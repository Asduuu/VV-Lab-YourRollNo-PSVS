# Operational Verification Checklist

| Operation | Verification question | Evidence to retain |
|---|---|---|
| Depositor registration | Is depositor active before acceptance? | Registration record and acceptance result |
| Deposit | Is box inspected, identified and assigned one owner/chamber? | Inspection, box and chamber records |
| Capacity check | Does deposit keep chamber count within limit? | Before/after count and decision |
| Normal withdrawal | Does requester match recorded owner? | Identity, owner match and release receipt |
| Emergency release | Is emergency authority approval valid? | Emergency reason, approver(s), requester and receipt |
| Temperature monitoring | Are readings within approved limits? | Calibrated sensor readings and alarms |
| Maintenance | Is the exception approved and exposure controlled? | Maintenance plan, duration, readings and sign-off |
| Viability | Does a low result create a regeneration task on time? | Test result, threshold and task timestamp |
| Redeposit | Has re-inspection passed? | Inspection report and acceptance decision |
| Audit | Are required actions recorded and protected? | Audit event record and access history |
